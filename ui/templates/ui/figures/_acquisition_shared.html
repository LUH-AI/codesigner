{% comment %}Everything else the script puts on the page. Same reason as the parameter names above: the catalogs are built from templates and Python, so a string written in acquisition.js reaches no translator and would sit in English inside an otherwise translated figure. `{name}` placeholders rather than concatenation, so a translator can move them — "Trial 3 of 12" does not put its numbers in that order in every language. Braces rather than `%(name)s`, which is the form Django uses elsewhere: extracting a template doubles every `%` to protect `blocktranslate`'s own interpolation, so the catalog key came out as `%%(rank)s` while the page asked for `%(rank)s` and the entry could never match. gettext has no opinion about a brace. These holes are filled by the script, not by Django, so nothing needs the `%` form.{% endcomment %}
