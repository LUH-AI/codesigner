{% comment %}What the model made of the stated belief, once somebody has asked. DynaBO's safeguard: a belief pointing somewhere the surrogate already thinks is bad costs trials, and the model usually has an opinion about the region it names. Asked for rather than continuous, and this is the reason it is a button — the judgement costs a model fit and two hundred acquisition evaluations, the same bargain "Requery Next Trials" makes. It also only means anything once there is a model: before the first run the policy is required to accept, and the banner says so rather than reporting approval that was never earned.{% endcomment %}

{% comment %}Shown while the run is still drawing its initial design, which happens before any surrogate exists — so nothing stated on this figure can reach those trials. Filled by the script from the recorded design size, never from counting origins (see `_initial_design_notice`).{% endcomment %}

{% comment %}Everything that states the prior, on one row above the panel it describes: the shape, its decay, the decay's factor, and whatever parameters the shape itself has. One row rather than two because they are one statement — reading the curve means reading all of it at once, and a parameter that sat on a second row below the picture was separated from the shape that decided it existed. Both selects are SMAC's own vocabulary: a prior is an AbstractInputPrior and the decay is one of DECAY_SHAPES, so what is chosen here is what would be handed to add_prior. Uniform is the resting state: it multiplies the acquisition by a constant, which cannot change a ranking, so it says exactly what stating no prior says.{% endcomment %}

{% comment %}Disabled rather than hidden. A control that vanishes takes its space with it and the figure jumps; one that greys out stays where the reader last saw it.{% endcomment %} {% comment %}β as a fraction of the trial budget, which is how πBO and DynaBO state it: β = N/10, ablated over N/50 … N/2.5 in DynaBO's Appendix F.9. The ratio rather than β itself, so it means the same across budgets. Disabled with the shape, because β is the factor *of* a schedule and has nothing to scale when nothing decays.{% endcomment %} {% comment %}Filled by the script from whichever distribution is chosen: a number field and a slider per parameter, bound both ways so dragging the curve moves the numbers and typing a number moves the curve. `display: contents` in the stylesheet, so those fields join this row rather than forming one of their own.{% endcomment %} {% comment %}How much of the stated belief still counts. A decaying prior weights the acquisition by its density raised to an exponent that falls as the run proceeds, and the exponent is the one number on this panel that moves without anybody touching a control — the curve had been redrawn from it all along without ever saying what it was. Shown only while it is doing something: with no decay it is 1 for the whole run, and saying so every time would be noise. {% endcomment %} {% comment %}Only while there is a design still to finish, and on by default. The initial design is drawn before any surrogate exists, so a belief cannot reach those trials — anchored before them it spends the whole phase fading while doing nothing and arrives at the first trial it can influence already weakened. Waiting is what the figure has always said happens; this is the control that makes it true. Hidden rather than absent once the design is over: there is nothing left to wait for then, and a checkbox offering to wait for it would be a control that cannot do anything.{% endcomment %} {% comment %}The undo for an afternoon of dragging. Every change on this panel saves as it is made, so there is no other way back to the statement the trials on screen actually came out of — and to uniform when there is nothing to go back to, which is the same thing as never having stated one.{% endcomment %}

{% comment %}A refusal is not an instruction. The model's opinion is worth hearing and is not worth more than the reader's — they may know something it does not, which is the entire reason for stating a belief in the first place — so a rejected prior is left exactly where it was and this asks. A native `` rather than `confirm()`: the question takes a sentence or two, and its two answers are "keep" and "discard" rather than "ok" and "cancel".{% endcomment %}
