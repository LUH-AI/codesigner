{% load i18n %} {% comment %} The initial-points block, laid out by hand because its five settings are only legible together: two caps, each of which can be switched off or left at SMAC's own value, and a choice of which one binds. Two columns because the caps are alternatives to each other, and reading them side by side is what makes "the smaller of these" mean anything. Each column goes: use this cap at all, use its default, and the value if not. "Use default" is not a stored setting — an empty field already means "SMAC's own", and a second thing recording the same fact could disagree with it. It is a control over whether the field is filled in, which is why it has no name and is never submitted. Without JavaScript it simply does not do anything, and an empty field still means the default. {% endcomment %}
