Paragraphs puts each paragraph on one line, so you can write without breaking lines by hand; on save, each paragraph you changed is wrapped to the line width, and the ones you didn't keep their lines exactly. Lines shows the text as it is in the file and saves it as typed. Each save goes straight into the .py file, and is refused if it would change anything but prose. Line numbers open the file in VS Code.
