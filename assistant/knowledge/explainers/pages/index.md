# Page explainers (draft)

- `home.md` (page-home): the home page (the assistant's chat, or a pointer to the sidebar) and the sidebar's Experiment Selection: New, Load, Bin, the recent list.
- `experiment-list.md` (page-experiment-list): All experiments, the paginated list behind "See all…".
- `new-experiment.md` (page-new-experiment): what New does, drafts, resuming a draft and discarding it.
- `setup-step-1.md` (page-setup-step-1): Setup: name, group, task, model or upload, dataset, target, validation method and its fields, seed.
- `setup-step-2.md` (page-setup-step-2): Optimizer: SMAC, Random Search, Grid Search and their settings, advanced search settings.
- `setup-step-3.md` (page-setup-step-3): Data: the three processing choices and the Data Handling tabs as they appear in setup.
- `setup-step-4.md` (page-setup-step-4): Priors & constraints, and Create experiment with what must be saved first.
- `dashboard.md` (page-dashboard): the experiment page: header, the four tabs and arranging figures, the page shown before the first trial.
- `dashboard-sidebar.md` (page-dashboard-sidebar): Experiment Evaluation (metric, run form, run status), HyperSHAP, Selected Configuration, exporting the selected trial.
- `data-handling.md` (page-data-handling): the Data Handling page, its nine tabs, which cards are built and which are planned.
- `experiment-settings.md` (page-experiment-settings): every per-experiment setting, inheriting the defaults, and resetting the figure layout.
- `timeline.md` (page-timeline): what the timeline records and how to read its entries.
- `export-import.md` (page-export-import): exporting a .ihpo, a model script and trial parameters; loading a .ihpo or a SMAC run; the bin and deleting.
- `account-and-groups.md` (page-account-and-groups): Appearance, Export preference, Account, groups, roles, sharing and transferring.
